## 7 · ⚠️ Bu oturumda ÖDENEN bedeller — tekrarlama

### 7.1 npm, `--` sonrasındaki argümanları YUTUYOR (bu makinede)

`npm run ai:ingest -- --source=admin-menu --dry-run` → npm `--source`'u kendi config'i
sandı, script **argümansız** koştu → **tüm kaynaklar + GERÇEK yazım** modunda canlıya
yazdı (dry-run değil!). Neyse ki idempotent + admin-menu belgeleri embed'siz aranamıyordu.
**Kural:** argümanlı `ai:ingest`/`ai:embed` **doğrudan node ile** koş
(`node scripts/ai-knowledge/ingest.mjs --source=… --dry-run`) ve çıktıda
**"(DRY RUN — yazma yok)" başlığını GÖRMEDEN** dry-run'a güvenme. KALANLAR'a da işlendi.

### 7.2 Emoji = UTF-16'da İKİ birim; metin bölücü çifti ortasından kesebiliyordu

🔴 (U+1F534) örtüşme sınırına denk gelince parça **yalnız vekil** `\uDD34` ile başlıyor;
`JSON.stringify` bunu geçerli JSON saydığı için hata İSTEMCİDE görünmüyor, PostgREST
(aeson) "Empty or invalid json" ile REDDEDİYOR — 93 parçadan tam 1'i, deterministik.
`chunk.mjs` düzeltildi (`trimLeadingLoneSurrogates` + `safeBoundaryEnd`), 3 test +
2/2 mutasyon. **Ders:** "geçici ağ hatası" sanma — aynı satır iki kez patlıyorsa
içerikte deterministik bir sebep ara; şüpheliyi `codePointAt` ile HEX dök.

### 7.3 Deploy Docker ister; Rancher Desktop motoru takılabiliyor

`supabase functions deploy` → "timed out dialing Hyper-V socket". Rancher Desktop süreci
açık görünse de motor ölüydü. **Çözüm (ölçüldü):** süreçleri `Stop-Process` +
`wsl -t rancher-desktop` + exe'yi yeniden başlat → ~1 dk'da motor geldi → deploy başarılı.

### 7.4 Untracked YENİ dosya pathspec'li commit'e kendiliğinden girmez

`git commit -- <yeni dosya>` → "pathspec did not match". Önce `git add <yeni dosya>`,
sonra pathspec'li commit.

### 7.5 Tam takım ~2–2.5 dk; arka planda koştur, `Start-Sleep` ile bekleme

`RouteErrorBoundary` testinin "sayfa çöktü" konsol gürültüsü **beklenen** çıktının
parçası, kırılma değil. Özeti `Test Files|Tests ` filtreli al.
