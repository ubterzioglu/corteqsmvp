## Nasıl kullanılır

- **Bir batch = bir oturum = bir commit.** Sırayla git; bir batch bitmeden diğerine geçme.
- Bitince başlığın başına ✅ koy ve altına **kanıtı** yaz (commit hash, ölçüm, SQL sonucu).
  "Yaptım" yazmak yetmez — bu repoda panolar üç kez yanlış "yapıldı" gösterdi.
- Rakamlar 27.09'da ölçüldü. Batch'e başlarken **yeniden ölç**; bayatlamış olabilir.
- **A-serisi bloke değildir:** U ve K maddeleri beklerken A'dan devam edilebilir.

## Her batch'te zorunlu doğrulama

```bash
npx tsc -p tsconfig.app.json --noEmit
npm run lint
npm run test                  # TAM takım — yalnız ilgili dosya yetmez (27.09'da CI tam bu yüzden kırıldı)
npm run check:dead
npm run ingest:tools:check    # src/lib/** değiştiyse; bayatsa `npm run ingest:tools` + openapi.yaml'ı da commit'le
git commit -m "..." -- <dosyalar>   # index başka oturumlarla paylaşılıyor, pathspec ŞART
gh run list --limit 1         # push sonrası CI yeşil mi
```

- Migration varsa: `supabase/migrations/applied/` altına, `psql -f` ile uygula, `schema_migrations` kaydını at.
- Edge function değiştiyse: `supabase functions deploy <ad> --project-ref injprdrsklkxgnaiixzh` — **Coolify deploy ETMEZ.**
- Yeni `cadde_*` hata kodu eklediysen `src/lib/cadde-rules.ts` haritasına Türkçesini yaz (`cadde-error-map.test.ts` kilitler).
- ⚠️ **Vitest'i büyük harfli `C:` ile çalıştır.** Küçük harfli `c:\...` cwd'de test dosyaları
  sahte kırılır (bilinen tuzak).
