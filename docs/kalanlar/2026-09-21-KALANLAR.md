## Çalışma biçimi — her adım için aynı beş aşama

**Hiçbir adım onaysız başlamaz.**

1. **Sun** — adımın kapsamı; karar gerekiyorsa seçenekler ve öneri.
2. **Onay al** — onaysız tek satır kod/SQL yazılmaz. Onay **yalnız o adım içindir**;
   bir adımın onayı bir sonrakine geçmez.
3. **Yap** — yalnız o adımın kapsamı. Yolda çıkan yeni iş **bu dosyaya yeni satır**
   olarak eklenir, mevcut adıma sızdırılmaz.
4. **Doğrula** — satırdaki doğrulama komutu çalıştırılır ve **çıktısı gösterilir.**
5. **İşaretle** — o satır ⬜ → ✅ yapılır; tarih + kanıt yazılır ve başlıktaki
   `Bitti: n / 96` sayacı güncellenir. **Bu aşama adımın parçasıdır** — bu dosya
   güncellenmeden adım bitmiş sayılmaz.

### Her adım için ortak doğrulama

- `npm run test` + `npm run lint` yeşil.
- `src/lib/**` altına dosya eklendi/silindiyse `npm run ingest:tools:check`.
- Migration eklendiyse `npm run check:migrations` **ve** dosya `applied/` altında.
- Faz 1 bittikten sonra ayrıca `npm run verify:quality`.
