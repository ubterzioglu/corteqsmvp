Teknik borç/dokümantasyon → Final doğrulama ve teslim.

Her konu planındaki çıkış kriteri tamamlanmadan bağımlı konuya geçilmez.

## Ortak kurallar

- Commitlerde yalnız açık dosya pathspec’i kullanılacak.
- Commit öncesi `git diff --cached --name-status` çalıştırılacak.
- Dosya ekleyen her batch sonrası `npx tsc -p tsconfig.app.json --noEmit` çalıştırılacak.
- Gerekli kontroller: `npm run test`, `npm run lint`, `npm run verify:text`,
  `npm run ingest:tools:check`, `npm run check:migrations`.
- Public dizin sonuçları PII’siz ve sayfalı olacak.
- Relocation için mock veri eklenmeyecek.
- Gemini Flash varsayılan AI sağlayıcısı olarak kalacak.
