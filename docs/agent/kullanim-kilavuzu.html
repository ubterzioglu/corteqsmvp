01Özet

İki yeni araç eklendi. İkisi de build-time Node script'idir — runtime'a (edge function / server.mjs) hiçbir bağımlılık eklemez.

ingest:tools

Tool Registry üretici

Edge function, worker ve *-api.ts modüllerini tarayıp her birini tek bir makinece-okunabilir kataloğa (docs/agent/tools.json) dönüştürür. Bir ajan kaynak kod okumadan hangi tool'un aktif/deprecated olduğunu, girdi şemasını, kullandığı tabloları ve versiyon pin'lerini buradan görür.

check:drift

Drift dedektörü

Dokümanlar ile gerçek kod arasındaki somut çelişkileri (versiyon pin'leri, deprecated endpoint, kaldırılmış tablo referansı) deklaratif kurallarla yakalar. docs/agent/drift-report.json üretir; drift varsa çıkış kodu 1 döner (CI gate).

Tek doğruluk kaynağı: git'e commit edilen docs/agent/tools.json'dur. Supabase ingest şeması, kataloğun sorgulanabilir ikincil projeksiyonudur — opsiyoneldir.

02Hızlı başlangıç

# 1) Kataloğu üret (docs/agent/tools.json yazar)
npm run ingest:tools

# 2) Drift kontrolü (rapor + bulgu varsa exit 1)
npm run check:drift

# 3) Uyarı modu — bulguları yazar ama her zaman exit 0 (CI rampası)
npm run check:drift:warn

# 4) Katalog güncel mi? (CI doğrulaması — bayatsa exit 1)
npm run ingest:tools:check

04tools.json yapısı

Örnek bir edge function girdisi (ajanın okuyacağı sözleşme):

{
  "tool_key": "edge.find_matches",
  "tool_name": "find-matches",
  "family": "edge_function",
  "status": "active",           // 410 dönerse otomatik "deprecated"
  "entrypoint": "supabase/functions/find-matches/index.ts",
  "interface_kind": "http",
  "input_schema": {
    "validation": "zod",
    "fields": ["sourceSubmissionId", "offers_needs", "field", "city", "country", "category", "persist"]
  },
  "tables_read_write": ["edge_rate_limits", "matches", "submissions"],
  "rpcs": [],
  "limits": { "MAX_BODY_BYTES": 16000, "RATE_LIMIT_MAX": 8, "RATE_LIMIT_WINDOW_SECONDS": 600 },
  "dependencies": ["@supabase/supabase-js@2.45.4", "zod@3.25.76", "gemini"],
  "version_pins": { "@supabase/supabase-js": "2.45.4", "zod": "3.25.76" },
  "evidence_path": "supabase/functions/find-matches/index.ts"
}

Üst düzeyde counts (toplam/edge/worker/modül sayıları) ve file_index (her dosyanın path · kind · module_family) bulunur.

Status nasıl belirlenir?

  • active — varsayılan.
  • deprecated — dosya hem 410 hem de "Deprecated" içeriyorsa otomatik. Örn. edge.lansman_admin.

05Opsiyonel: Supabase'e push

Kataloğu sorgulanabilir kılmak için ingest.tools tablosuna upsert edebilirsiniz. Önce migration uygulanmalı, sonra --push flag'i ile çalıştırın:

# Migration: supabase/migrations/20260624100000_agent_ingest_schema.sql
# (ingest.repo_files · ingest.repo_symbols · ingest.tools + RLS)

node scripts/ingest-tools.mjs --push

--push, .env.local'dan (veya ortam değişkenlerinden) SUPABASE_URL + SUPABASE_SERVICE_ROLE_KEY okur ve service-role ile yazar.

RLS: ingest şeması deny-all varsayılanındadır; yalnız public.is_admin(auth.uid()) olan kullanıcı okuyabilir. Service role RLS'i bypass eder (yalnız push için). Anon/authenticated rol erişemez.

06check:drift — çelişkileri yakalamak

Dedektör, deklaratif kuralları çalıştırıp docs/agent/drift-report.json üretir. Tool kataloğu varsa kurallara bağlam olarak verilir; önce ingest:tools çalıştırmak güncel sonuç verir.

Şu an aktif kurallar

KuralŞiddetNe yakalar
router-version-drifthighpackage.json react-router-dom major'ı ile AGENT_CONTEXT.md / ARCHITECTURE.md metni uyuşmuyor

Çıkış kodları: Bulgu varsa check:drift → exit 1 (gate); check:drift:warn → her zaman exit 0 (rapor üretir, build'i kırmaz).

Kalan bilinen bulgu: supabase-js-version-drift (edge 2.45.4 · worker 2.49.1 · frontend 2.101.1). Bu kod durumudur, doküman değil — çözümü edge function'ları güncelleyip yeniden deploy etmektir (Faz 1 dışı).

07Yeni drift kuralı eklemek

Kurallar scripts/agent/drift-rules.mjs içinde saf fonksiyonlardır: (ctx) => Finding[]. ctx şunları sağlar: ctx.read(path) · ctx.pkg · ctx.catalog.

function ruleOrnek(ctx) {
  const readme = ctx.read("README.md");
  if (!/eski_desen/.test(readme)) return [];
  return [{
    rule: "ornek-drift",
    severity: "high",        // high | medium | error
    message: "README eski deseni anlatıyor ama X artık geçerli.",
    evidence: [{ path: "README.md" }]
  }];
}

// Diziye ekle:
export const driftRules = [ ..., ruleOrnek ];

Bir kural hata fırlatırsa dedektör çökmez; severity: "error" bulgusu olarak raporlanır.

10SSS & kısıtlar

Neden tam TS AST parser yok?

Zod şemaları edge function'larda zaten açık metin. İlk sürüm hafif regex/satır taramayla yeterli sonuç veriyor (örn. find-matches'in 7 alanı + 3 limiti doğru çıkarıldı). İhtiyaç olursa ts-morph sonradan extract.mjs'e eklenebilir — Faz 1'i bloklamaz.

Boş edge klasörleri?

chat-register klasöründe index.ts yok; bu yüzden tool olarak kataloglanmaz. Bu doğru davranıştır — katalog gerçeği gösterir, dizin listesini değil.

Kapsam dışı (sonraki fazlar)

  • OpenAPI / iç ajan API sözleşmeleri
  • Agent router / executor / verifier zinciri
  • ops.* analytics + anonim (DP) raporlama + admin dashboard UI
  • MongoDB ikincil store
Türkçe metin kuralı: Yeni script'ler ASCII anahtar kelimeler kullanır; kullanıcıya görünen Türkçe çıktıda bare toUpperCase/toLowerCase yoktur. npm run verify:text tüm yeni dosyalarda temiz geçer (UTF-8, mojibake yok).
